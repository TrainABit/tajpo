# Security Policy

## Reporting a vulnerability

Please do not open a public issue for a suspected vulnerability or for a
credential/clipboard exposure. Use GitHub's private vulnerability reporting
for this repository when available. If it is not enabled, contact the
maintainer through a private channel and include:

- affected version/build and macOS version,
- reproduction steps using synthetic/non-sensitive text,
- the expected and observed behavior,
- whether any real key or clipboard content was exposed.

Do not include an API key, selected text, or private document content in a
report. The maintainer will acknowledge the report and coordinate a fix and
disclosure timeline.
